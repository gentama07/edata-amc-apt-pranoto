# Audit antislop 002 (2026-11-16)

## Cakupan

Audit source dan sesi Chrome produksi untuk tampilan desktop, navigasi, Ringkasan, Log, Input, Laporan, Persuratan, dan menu Pengguna pada role Admin, Personel AMC, Pimpinan, serta Ground Handling. Pengujian produksi hanya membaca halaman dan memeriksa validasi form kosong; tidak ada surat, file, chat, perubahan akun, atau data pergerakan yang dikirim, dibuat, diubah, maupun dihapus.

## Temuan dan perbaikan

1. Tautan “Kembali ke masuk AMC” dari portal Ground Handling mengarah kembali ke portal yang sama. Tautan kini menuju halaman login AMC.
2. Banyak teks bantuan, metadata, label, status, dan tombol berukuran 7–11 px. Ukuran minimum teks sekarang 12–14 px; navigasi bawah tetap muat pada telepon. Pilihan warna teks sekunder memenuhi 4,5:1 pada latar terang, sedangkan warna seri grafik dan batas kontrol memenuhi sedikitnya 3:1 pada latarnya.
3. Tombol ubah kata sandi disembunyikan pada layar kecil tanpa pengganti. Tautan kini tersedia di menu navigasi mobile. Header membungkus kontrol pada lebar 430 px ke bawah dan drawer mengikuti banner demo. Menu tertutup tidak lagi memasukkan tautan tersembunyi ke urutan Tab, tombol menu menyebut state dan target, dan Escape mengembalikan fokus ke pemicu.
4. Dialog ubah kata sandi sekarang memfokuskan kolom pertama dan menahan urutan Tab di dalam dialog.
5. Validasi PDF sebelumnya bergantung pada tipe MIME yang dikirim browser dan terjadi setelah metadata surat disimpan. Form sekarang memeriksa ekstensi, ukuran, dan tanda tangan `%PDF-` sebelum menyimpan surat; Edge Function memeriksanya kembali sebelum meneruskan berkas ke Apps Script.
6. Policy insert Ground Handling kini membatasi surat baru ke status `Baru` dan mencegah pembuatan surat balasan sebagai surat masuk.
7. Pratinjau lokal memvalidasi bentuk data `localStorage`; isi yang rusak tidak lagi membuat aplikasi mencoba membaca daftar yang bukan array.
8. Ground Handling dapat melihat dan mengubah nama pengirim, tetapi perusahaan terkunci ke organisasi profil. Empty state surat kini memisahkan judul dan keterangan; input unggah ulang PDF teknis disembunyikan; metadata surat memakai pemisah yang tetap terbaca saat style flex tidak diterapkan.
9. Form surat memakai validasi aplikasi berbahasa Indonesia dan penanda kolom wajib yang konsisten, menggantikan tooltip required bawaan Chrome yang berbahasa Inggris.
10. Audit kebijakan menemukan role Pimpinan masih bisa mengubah status surat lewat permintaan database langsung walau kontrolnya disembunyikan di UI. Policy update kini dibatasi ke Admin/Personel; Pimpinan tetap dapat mengirim chat dan surat balasan.
11. Bila unggah Drive gagal setelah metadata surat atau balasan tersimpan, percobaan ulang sebelumnya bisa membuat record duplikat. Form sekarang mempertahankan ID record tersebut dan mengulang unggah ke record yang sama.
12. Build awal memberi peringatan CSS karena dua baris keluaran terminal tersisip di `styles.css`; baris itu sudah dibuang agar stylesheet diproses bersih.

## Hasil audit browser per peran

- **Admin:** menu operasional dan Pengguna tersedia; tabel menunjukkan tiga akun aktif dengan peran Admin, Pimpinan, dan Ground Handling. Input pergerakan tersedia. Persuratan menampilkan status, pengelolaan surat, dan percakapan.
- **Personel AMC:** tidak melihat menu Pengguna; tersedia Log, Input, Laporan, dan Persuratan. Bisa membuka form surat, melihat kontrol status/hapus, serta membuka composer chat dan PDF. Tombol kirim nonaktif ketika kosong.
- **Pimpinan:** hanya melihat Ringkasan, Log, Laporan, dan Persuratan. Tombol Input/Pengguna, status yang dapat diubah, dan hapus tidak muncul. Chat dan balasan PDF tersedia sesuai alur balasan Pimpinan yang diminta.
- **Ground Handling:** hanya melihat Persuratan; portal mengunci perusahaan ke Gapura Angkasa, mengisi nama awal dari profil, dan menampilkan daftar kosong untuk surat milik akun itu. Form meminta tanggal, nama, perusahaan, perihal, serta PDF; upload dan pengiriman tidak dicoba.
- Pada laporan November yang terlihat oleh Admin dan Pimpinan, angka total 269 penumpang, 780 kg bagasi, dan 944 kg kargo muncul bersama nol hitungan ARR/DEP dan satu rekap harian bernilai nol. Perhitungan ARR/DEP memakai ada/tidaknya nomor penerbangan, sehingga entri lama tanpa nomor dapat menjelaskan perbedaan; penyebab spesifik belum dipastikan tanpa pemeriksaan record sumber.
- Halaman produksi yang diaudit masih menampilkan teks kecil dan metadata surat yang rapat. Perbaikan keterbacaan serta format Persuratan berada di workspace; belum diverifikasi pada situs produksi setelah perubahan.

## Verifikasi

- `npm run lint`: lolos.
- `npm test`: 6 tes lolos.
- `npm run build`: lolos.
- Kontras dihitung dengan rumus WCAG karena Python contrast checker tidak dapat dijalankan di environment ini: teks `#6f6f76` pada `#f5f5f7` 4,58:1; teks yang sama pada putih 4,99:1; seri grafik `#4b8fcf` pada putih 3,43:1 dan pada kartu gelap 4,57:1; batas kontrol `#8b8b91` pada putih 3,39:1 dan pada kanvas terang 3,11:1.
- Taste skill: `GATE: ERROR`. Chrome headless keluar sebelum mulai (`Chrome exited early` / `Chrome did not start`); pemeriksaan salinan dan layout tidak berjalan. Sesuai petunjuk skill, gate tidak dijalankan ulang.
- Sesudah perbaikan Ground Handling: `npm run lint`, `npm test` (6 tes), `npm run build`, dan `git diff --check` lolos.
- Revisi policy Pimpinan sudah tercakup pada migrasi 003 dan migrasi koreksi 004 agar tetap berlaku jika 003 sudah pernah diterapkan. Status migrasi 003/004 pada project Supabase produksi belum diverifikasi.

## Batas pemeriksaan

Alur submit surat, validasi file PDF nyata, chat, upload ke Drive, realtime lintas akun, dan kinerja policy RLS lewat request langsung tidak diuji pada produksi karena membutuhkan transaksi atau data uji. Build dan tes logika lokal lolos, tetapi website produksi belum menerima patch visual terbaru dan migrasi 004 belum diterapkan.
