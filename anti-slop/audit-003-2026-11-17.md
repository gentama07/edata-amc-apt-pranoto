# Audit UI E-data AMC — 17 November 2026

## Cakupan

- Login lokal dan tampilan autentikasi produksi tanpa mengirim kredensial.
- Pengalihan lupa sandi dan halaman tautan pemulihan yang tidak valid.
- Dashboard desktop, login dan dashboard pada lebar 320 px.
- Navigasi peran demo Pimpinan dan Ground Handling.
- Kontras teks utama pada tema terang serta status layanan pada tema gelap.

## Perbaikan

- Mengganti logo APT pada login dan header tema terang dengan PNG yang diberikan. Logo SVG putih tetap dipakai di tema gelap.
- Menghapus tautan publik “Lapor atau kirim surat” dari login.
- Mengganti teks footer login dengan status koneksi Auth dan REST Supabase yang diperiksa saat halaman dibuka dan tiap 30 detik. Mode demo menampilkan “Pratinjau lokal”; status layanan bermasalah tidak ditampilkan sebagai aktif.
- Menambahkan kontrol jeda gerak untuk cincin latar dan lampu status. Animasi berhenti jika `prefers-reduced-motion` aktif.
- Membatasi halaman reset agar hanya menerima event `PASSWORD_RECOVERY` dari Supabase. URL `?recovery=1` tanpa sesi reset menampilkan petunjuk tautan tidak berlaku.
- Memperjelas pesan mode demo, menambahkan `name` dan `spellCheck` pada input autentikasi, serta memperbaiki status berhasil pada pemulihan sandi.
- Memperbaiki fokus kolom pencarian dan warna teks bertema terang.
- Menghapus scroll horizontal pada lebar 320 px dan memastikan login mulai dari atas setelah keluar.

## Hasil pemeriksaan

- `npm run build`: lulus.
- `npm run lint`: lulus.
- `npm test`: 6 lulus.
- Browser lokal: login, pergantian tema, jeda animasi, URL reset tidak valid, dashboard, serta navigasi Pimpinan dan Ground Handling teramati.
- Kontras hasil hitung: muted terang 4.86:1; kicker terang 5.08:1; hijau personel 5.34:1; avatar Ground Handling 6.65:1; indikator status di panel gelap 8.13–9.16:1.

## Batas audit

- Permintaan reset kata sandi ke email dan penyelesaian reset menggunakan tautan Supabase yang nyata belum dikirim atau diverifikasi. Perlu menguji allowlist Redirect URLs dan template email pada Supabase produksi.
- Taste Gate berjalan di Chrome headless, tetapi melaporkan 21 kegagalan untuk struktur autentikasi dua panel: mengharapkan landing page promosi dengan hero satu bagian, CTA di kolom hero, gambar di setiap kolom, serta satu garis kontainer di seluruh halaman. Temuan copy berbahasa Indonesia juga dinilai memakai kategori bahasa Inggris. Pemeriksaan ini dicatat sebagai ketidakcocokan gate terhadap layar autentikasi aplikasi; tidak ada kriteria yang disembunyikan dengan waiver.
