# Audit desain E-data AMC — 17 November 2026

## Cakupan dan metode

Audit mencakup halaman login dan pemulihan akun yang tampil di Chrome, lalu tinjauan kode untuk Ringkasan, Log pergerakan, Input data, Laporan, Persuratan, Pengguna, navigasi, tema terang/gelap, formulir, modal, dan aturan responsif. Acuan yang dipakai: Anti-Slop, Taste, antislop-human, antislop-layoutmobile, antislop-copywriting, dan Web Interface Guidelines. Rasio kontras dihitung dengan formula luminansi WCAG; script skill tidak dapat dijalankan karena Python launcher tidak tersedia di environment ini.

Kondisi yang terlihat di Chrome: login produksi pada desktop. Snapshot sebelumnya pada sesi ini menampilkan pesan berbahasa Inggris `Email address is invalid` di alur pemulihan; saya tidak mengirim permintaan reset baru. Akun produksi tidak dimasukkan ulang dalam audit ini.

## Ringkasan

Struktur halaman login punya identitas yang jelas: panel gelap dengan motif ring, logo lokal, aksen biru, dan form yang tenang. Navigasi peran dan empty state operasional juga punya pola yang konsisten di kode. Temuan utama ada di kontras kontrol, fokus keyboard saat dialog terbuka, serta ukuran teks untuk data yang padat.

## Temuan

### Prioritas tinggi

1. **Kontras placeholder dan batas field belum cukup.** Placeholder `#a5a5ac` pada putih hanya **2,45:1**. Batas `#e5e5e9` pada putih **1,26:1**, dan batas `#39393d` pada panel gelap **1,36:1**. Placeholder gagal target 4,5:1 untuk teks normal; batas field kurang dari target 3:1 untuk komponen. Atur warna placeholder memakai token muted yang teruji, dan buat token batas field terpisah untuk tema terang/gelap. Lokasi: `src/styles.css:20,43,287,289`.

### Prioritas menengah

2. **Dialog tidak menjaga fokus keyboard.** Dialog ubah sandi menutup dengan Escape, tetapi tidak memindahkan fokus ke dalam dialog atau mengembalikan fokus ke pemicu; dialog hapus pergerakan juga tidak menangani Escape. `aria-modal` sendiri tidak mencegah Tab berpindah ke kontrol di belakang modal. Tambahkan fokus awal, focus trap, pemulihan fokus, dan Escape untuk dialog konfirmasi. Lokasi: `src/components/ChangePasswordModal.jsx:12,28`; `src/pages/Movements.jsx:44`.

3. **Teks data terlalu kecil di beberapa area kerja.** Filter 8–10px, header/isi tabel 8–9px, catatan KPI 9px, dan keterangan grafik 8–9px membuat layar operasional padat sulit dipindai. Naikkan teks informasi utama ke kisaran 11–12px dan pertahankan kepadatan lewat jarak serta lebar tabel, bukan mengecilkan teks. Lokasi: `src/styles.css:143,158,210,223,233,242,244,286`.

4. **Pesan gagal reset sandi menampilkan teks backend mentah.** Snapshot browser menunjukkan error Inggris `Email address is invalid` pada halaman berbahasa Indonesia. Pesan itu tidak memberi langkah pemulihan. Petakan error Auth ke copy Indonesia yang jelas; verifikasi terpisah apakah alamat akun dan konfigurasi email Supabase memang valid. Lokasi: `src/pages/Login.jsx:67`.

5. **Input ubah sandi belum memiliki `name`.** Label dan `autocomplete` sudah ada, namun kontrol lama/baru/konfirmasi tidak mempunyai nama eksplisit. Tambahkan nama yang jelas untuk autofill/password manager yang konsisten. Lokasi: `src/components/ChangePasswordModal.jsx:34-36`.

## Hasil Taste dan batas verifikasi

`GATE: FAIL 20 (round 2 of 3)`. Sebagian besar temuan berasal dari asumsi checker situs pemasaran: hero satu layar, CTA promosi di kedua panel, satu container lintas split-screen, dan foto/mock pada layar login. Itu tidak cocok dengan login aplikasi operasional. Checker browser visual juga gagal dijalankan karena Chrome test tidak mulai, jadi temuan tersebut tidak saya anggap sebagai bukti kerusakan UI.

Chrome yang dipakai pengguna sedang menerima input langsung, dan tab pratinjau lokal tidak dapat dibuka di browser in-app. Karena itu audit ini tidak mengulang login empat role atau pemeriksaan viewport manual. Uji tampilan per role dan lebar 320px yang dilakukan pada audit browser sebelumnya tetap menjadi bukti pendukung, tetapi bukan pengganti pemeriksaan ulang sesi ini.

## Perbaikan setelah audit

- Field sekarang memakai batas tema terang/gelap dengan kontras di atas 3:1; placeholder memakai token muted dengan kontras di atas 4,5:1.
- Dialog ubah sandi dan hapus pergerakan memindahkan fokus saat dibuka, menjaga Tab tetap di dalam dialog, menutup lewat Escape, dan mengembalikan fokus setelah ditutup.
- Teks filter, tabel, KPI, timeline, formulir, dan persuratan yang paling kecil dinaikkan ke 10–12px.
- Error Auth untuk reset sandi kini ditampilkan dalam bahasa Indonesia dengan langkah berikutnya; pengiriman email sebenarnya dan konfigurasi SMTP/Auth belum diuji.
- Field ubah sandi diberi nama eksplisit untuk password manager.

Validasi kode setelah perubahan: `npm run lint`, `npm run build`, dan `npm test` lulus (6 tes).
